# zachross.io

Source for [zachross.io](https://zachross.io), built with [Astro](https://astro.build) and deployed to Cloudflare Workers.

```sh
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
npm run check    # type-check
npm run check:csp  # after a build: verify CSP hashes
npm run format   # Prettier
```

Requires Node 24+ (see `.nvmrc`).
